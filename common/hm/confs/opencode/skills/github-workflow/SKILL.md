# GitHub Workflow

- Inspect repository, current branch, remotes, status, and diff before proposing GitHub actions.
- Use focused Issues and PRs with clear scope and acceptance criteria.
- PR descriptions should summarize motivation, implementation, testing, risks, and screenshots/logs when useful.
- Use Conventional Commits only if the repository follows that convention.
- Never push, merge, close issues, publish releases, or modify repository settings without explicit approval.
- Do not expose tokens or secrets.
