# DevOps Engineering

- Inspect existing workflows, Dockerfiles, compose files, deployment manifests, and scripts before changing them.
- Prefer reproducible builds, pinned dependencies, health checks, least privilege, and small deployment changes.
- Keep secrets out of logs, shell output, source control, and generated artifacts.
- Distinguish local, staging, and production environments.
- Include deployment verification and rollback.
- Do not deploy, destroy infrastructure, modify production resources, or rotate credentials without explicit approval.
